MakorX.AI HR — Design System

Desktop-only HR platform of Makor Capital (employees, pools, time tracking, requests, My Profile). Source of truth = the built app makor-hr/employees.html (Figma is irrelevant by owner decision). Every value below is reproduced from the app's effective CSS; where the app is silent the system is EXTENDED and the item carries a visible Extended badge. Light and dark are ONE system (class dark on <body>); use the toggle in the top bar. Class names are the app's own, so design-system markup == app markup. Not in the app (do not build): a left sidebar, 38px search, a dark #111214 nav shell.

Colours (light | dark pairs)

Every colour is a ROLE token (--color-<role>); the app itself defines only two CSS custom properties, everything else was a literal. Light values live on :root, dark pairs on body.dark (the app's own switch; .theme-light / .theme-dark force a theme on a container). Each swatch sits on the page background of its theme so translucent dark values read correctly. Values are the tokens' own (rendered through var()). Dark values with no source in the app are flagged in the bug table.
