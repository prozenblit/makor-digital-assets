# MakorX.AI HR app — "My Profile" self-service screens (harvest)

Source of truth: `makor-hr/employees.html` (5743 lines), served `http://localhost:3456/makor-hr/employees`.
Method: CSS + JS templates read in full; then computed styles / bounding boxes measured in a live browser tab (own tab, Chrome emulation 1440x900 and 1920x1080, light and dark). Nothing in the app or any other file was written.

Conventions: `L123` = line in employees.html. Values are EFFECTIVE (cascade resolved). "Computed" = measured with getComputedStyle.
Measurement caveats (so nobody "fixes" them): the harness ran at devicePixelRatio 1.5, so Chrome snaps borders: CSS `1px` reads as `0.666667px`, `1.5px` reads `1.33333px`, `2.5px` reads `2px`. **Always use the SOURCE border widths listed here (1px / 1.5px / 2px / 2.5px).** Transitions are not progressed in a hidden tab, so mid-transition computed values were re-measured with transitions disabled.
Palette shorthand used below: teal `#005268`, dark-teal-hover `#003d50`/`#004257`, border `#e5e7ec`, text `#1a1a1a`, muted `#7c8dac`, faint `#a8b6cd`, surface-alt `#f5f5f8`, page-bg `#f5f5f8`. Dark: page `#111214`, card `#202226`, raised/popover `#26292e`, text `#e2e8f4`, text-2 `#c8d4e8`, muted `#8a97aa`, faint `#505a6c`, accent `#0cb8d0`, hairline `rgba(255,255,255,0.07)`, divider `rgba(255,255,255,0.12)`, control-border `rgba(255,255,255,0.10)`.

## 0. How My Profile is reached, structure, routing

* There is NO separate page. `employees.html` hosts both the HR app and "My Profile". `<div id="myprofile-view">` (L2135–3194) is a fixed overlay under the nav; the HR views (`#emp-view`, `#pool-view`, `#requests-view`, `#timetracking-view`) are hidden when it is shown (L5515–5535).
* Entry points: (a) apps grid icon (top-left, `.nav-apps-icon`, L1727) → `#appDrop` → item "My Profile" (`#appdrop-myprofile`, L1765, `onclick="showMyInfoView();toggleAppDrop()"`); (b) URL hash `#myinfo`, `#myinfo:wfh`, `#myinfo:timeoff`, `#myinfo:timesheet`, `#people` (DOMContentLoaded handler L4577–4592; `#myinfo:<tab>` clicks the matching `.profile-tab[data-tab]`).
* `setNavApp('myprofile')` (L5495): `#navSub` text → "My Profile"; hides `#hr-nav-links`, shows `#myprofile-nav-links` (two links: **My Info** `#nav-myinfo`, **People** `#nav-people`); app-drop item `#appdrop-myprofile` gets `.app-drop-item-current`, its "Current" badge is shown and HR's hidden.
* `showMyInfoView()` (L5515): left column + tab bar visible, panel `#panel-myinfo` (tab "Information") active. `showPeopleView()` (L5526): `wsSwitchSection('people')` hides `.left-col` and `.content-tabs` (display:none) and activates `#panel-directory` – so the directory is the "People" nav page, NOT a tab.
* Tab bar (L2219–2224): `Information` (data-tab `myinfo`), `WFH Schedule` (`wfh`), `Time Off` (`timeoff`), `Timesheets` (`timesheet`). Click handler (wsInit, L5480–5489): remove `.active` on all `.profile-tab` and `.ws-panel`, add to the clicked tab and `#panel-<data-tab>`, `#myprofile-view.scrollTo(0,0)`, `history.replaceState(null,'','#myinfo:'+tab)`. No transition/animation on panel switching (instant display swap).
* `#panel-today` (L2227) is permanently hidden: inline `style="display:none!important"` and there is no tab for it (comment "Today panel removed"). Its CSS/markup still exists; its measured styles are in §9 for completeness. `setGreeting()` is a no-op.
* Dead JS (reference DOM that does not exist): `toggleEdit()` / `PFIELDS` / `#editPersonalBtn` / `.info-field-input` (L4665–4685). My Info does NOT use an Edit/Save/Cancel toggle; see §3 "dirty tracking".
* `wsInit()` (first entry only): `calcStats()`, `renderDirectory()`, `renderWFH()`, `renderRequests('all')`, tab listeners, `setTimeout(dpRender,100)`, `syncCardHeight()` + resize listener.
* No `@media` query anywhere in the stylesheet (searched `@media`, `@supports`, `prefers-`): layout is not responsive; fixed-width desktop layout. Only one `@keyframes` exists: `dir-flash` (L731).
* Dark mode: `body.dark`, toggled by avatar `#navAvatar` (L1746, "PR") → `#profileDrop` → "Dark mode" row (`toggleDarkMode()` L5720) which also writes `localStorage['makor-dm']='1'|'0'` and is re-applied on load (L5734–5740). The switch is `.dm-switch` / `.dm-thumb`.
* Fonts: `Geist` 100–900 (body, all UI) and `Lexend Exa` (nav wordmark only), Google Fonts link L9. Base: `body{font-family:'Geist',-apple-system,BlinkMacSystemFont,sans-serif;background:#fff;color:#1a1a1a;font-size:14px;line-height:1.5}` (L13, repeated L487 + `overflow-y:scroll`). `input,select,textarea,button{font-family:inherit;font-size:inherit}` (L14). Global reset `*{box-sizing:border-box;margin:0;padding:0}` (L11).
* Because `body{overflow-y:scroll}` (L487) a permanent 15px scrollbar gutter exists on Windows; the nav/fixed overlays are therefore 1424.67px wide at a 1440 viewport (and 1904.67px at 1920). Layout numbers below at "1440" are that.
