## 2. Class naming scheme (components.css PART 1)
Figma component name -> kebab class; BEM-ish children `__x`; modifiers `--x`; forced states `.is-hover .is-focus .is-disabled .is-active .is-open .is-error .is-checked .is-indeterminate .is-on`.
Strokes are INSIDE-aligned in Figma and implemented as `box-shadow: inset 0 0 0 <w> <colour>` (no layout shift, 1.2/1.5px preserved, padding equals the Figma padding). Stage 2: use the same technique (right/bottom/left single-side: `inset -1px 0 0 0`, `inset 0 -1px 0 0`, `inset 1px 0 0 0`); when you need stroke + shadow combine them in one `box-shadow` list.
Icons: `<span class="icon icon-<asset-name>"></span>` (51 classes, size = exported box, default colour = Figma colour of that icon); override with `.icon-c-{inherit,black,grey-1,grey-2,brand,orange,blue,red,green,white}`, `.icon-flip-x/-y`. Coloured assets (logos, circle-x, checkbox svgs, list-chevrons-toggle, noun-ai/pdf/zoom, bell-notify, bookmark-24/32, nav-item-book-active-40, radio dot) are `<img>`; `img.circle-x` helper only. `icon-arrow-up-down-32-button` is a plain image (backing rect baked into the export, not mask-able).
Typography utilities `.t-<key>`, `.t-underline`, `.t-strike`, colour utils `.c-*`, text roles `.text-body .text-nav-section .text-title .text-deal-title .text-login-title .text-th .text-th-10 .text-cell-10`.
