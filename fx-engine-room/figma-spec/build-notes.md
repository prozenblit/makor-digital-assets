## 5. Conflicts / decisions (put in CLAUDE.md + showcase "Known Figma inconsistencies")
1. Primary action = purple #A4A4FF with BLACK SemiBold 14 label (screens override the library New/Add teal). `.btn` default = purple; `.btn-teal` = library default.
2. Outlined teal: screens #30F0D6 (default `.btn-outline-teal`), library raw #00FEA9 (`--library` alt; hover #1B5244).
3. Cancel set: two variants both named "Disabled"; first is hover (white@0.3), second the real disabled. `.btn-cancel.is-hover` / `.is-disabled`.
4. With dropdown hover drawn r4/gap 10 vs default r3/gap 8: kept r3/8 (`.is-hover--alt-geometry` = alt). csv hover height 30 vs 24: kept 24 (`--alt-hover-height`).
5. status disabled: label stays purple, chevron grey (reproduced). Outlined blue/yellow hover fill sits on a wrapper in Figma; here on the button itself.
6. Inverted switch knob: ON = knob LEFT (x2), OFF = knob RIGHT (x18; 17 in "Switch with text"). Reproduced; `.switch--conventional` alt. Set naming bugs: "falce", "Variant2".
7. Input fill is SURFACE-AWARE (#171719/#000 -> #242428, #242428 modal -> #39393C, #39393C inner -> #242428); library default #39393C. Filled/locked fields drawn two ways (keep fill vs. fill removed + 1px #707079): both supported (`.is-locked`).
8. Checkbox unchecked fill bound to 3 variables (same #39393C x2 + #242428). 17x16 stretched variant kept as `.checkbox--wide`.
9. `.btn-xs` (48x20): Figma lists padding 11/12/11/12 on a 20px frame; only horizontal 12 reproduced.
10. Tooltip shadow has 2 recipes (-1,2,4,0 @0.4 = the local effect style; -2,2,4,1 @0.5): default = style, `--strong-shadow` alt; popovers use the strong one.
11. Checkbox in 17x16 / indeterminate asset is the exported 24x24 holder cropped to 16x16 (box at 4,4).
12. Dropdown caret: Figma node 12x8 polygon, exported asset 11x6; asset size used. Status chevron: node 8x4, asset 10x6 (hug width ~1.3px wider than Figma 96).
13. Font heights: Figma text boxes are cap-height boxes; CSS uses `normal` line-height with fixed control heights (error <= 0.4px). Hug widths differ from Figma by < 1.5px due to font metric differences.
