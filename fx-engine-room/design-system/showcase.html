Every value on this page is quoted from the harvest; Extended marks anything Figma does not draw (derived only from existing tokens).

text-box: trim-both is not supported by this browser. The loose-text positions of this system (page titles, modal titles, section labels, value boxes, detail headers…) need text-box: trim-both cap alphabetic (Chrome 133+ / Safari 18.2+) to match Figma's cap-height trimming. Without it those texts render about 5px lower than Figma and cap-to-cap margins grow. Controls with fixed heights and centred content are unaffected.
